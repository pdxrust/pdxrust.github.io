Software-Defined Radios (SDRs) let you capture raw radio signals with commodity
hardware. Luke Petherbridge will discuss what it takes to process those signals
and render a live, scrolling frequency display in a web browser using Rust,
Leptos, WebGL2, and WebAssembly (WASM) using digital signal processing like the
Fast Fourier Transform (FFT). No JavaScript was harmed in the making of this
software.
